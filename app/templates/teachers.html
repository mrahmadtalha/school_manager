Import Teachers from Excel / CSV
Easiest way: download the template below, fill one teacher per row, then upload it here.

Mandatory columns (red in the template):
Teacher Name, Joining Date, Qualification
Optional columns: Teacher ID, Designation, Gender, Salary Type, Monthly Salary, Hourly Rate, Date of Birth, CNIC, Address, Contact Number, Emergency Contact Number, Assigned Classes, Assigned Subjects, Previous Experience (Years), Previous Salary and any custom fields set up in Settings.

Good to know:
  • A row with a mandatory value missing is skipped and reported — nothing incomplete is saved
  • Dates: YYYY-MM-DD or DD/MM/YYYY
  • Teacher ID is optional: leave it blank and the next free ID (T001, T002 …) is given automatically
  • Existing teachers are never overwritten. Rows are skipped if the Teacher ID or CNIC is already registered, or the same teacher already exists
  • Assigned Classes / Subjects must already exist; separate several with commas
  • After the import you see exactly which rows were skipped and why
  • Supports .xlsx and .csv
