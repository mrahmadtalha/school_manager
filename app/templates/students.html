Import Students from Excel / CSV
Easiest way: download the template below, fill one student per row, then upload it here.

Mandatory columns (red in the template):
Student Name, Father Name, Class, Guardian Phone, Address
Optional columns: Roll Number, Section, Gender, Date of Birth, Admission No, Admission Date, Sponsor Type, Sponsor CNIC, Monthly Fee, Discount Type, Discount Value and any custom fields set up in Settings.

Good to know:
  • A row with a mandatory value missing is skipped and reported — nothing incomplete is saved
  • Class must match an existing class exactly — e.g. Class 5 not 5
  • Roll Number is optional: leave it blank and the next free number in the class is given automatically (each class starts at {{ first_roll_number }})
  • Existing students are never overwritten. Rows are skipped if the Roll Number is already used in that class, the Admission No already exists, or the same student (name + father name + class) is already registered
  • After the import you see exactly which rows were skipped and why
  • Supports .xlsx and .csv
